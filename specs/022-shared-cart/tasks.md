# Tasks: Shared Kitchen Cart with People, Meals, Scale Factor and Single-Editor Locks

**Input**: Design documents from `specs/022-shared-cart/`

**Prerequisites** (regenerated 2026-10-29 after clarify: idle limit, access loss, editing bar; Phase 9 added 2026-10-29 after the UI clarification: cart-icon button, toasts above the tab bar, Cart-page-only editing bar): plan.md, spec.md, research.md, data-model.md, contracts/cart-api.md, contracts/recipe-lock-api.md, contracts/cart-ui.md, quickstart.md

**Organization**: Grouped by user story (spec.md: US1 P1 add/see/remove, US2 P1 people/meals/factor, US3 P1 shared cart with one editor, US4 P1 recipe edit lock, US5 P2 consistency and add count). Because every cart write goes through the editor lock and draft (research R6, R7), the migration, the domain rules, the lock liveness query and the session reference are Foundational (Phase 2). US1 delivers the draft/save path with the minimum lock UI; US3 adds the notice for other members and the lock-ending cases.

**Tests**: The spec does not request TDD, but constitution §6 requires domain tests, application tests with fakes and integration tests in Compose, so test tasks are included.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1–US5 (story phases only)
- Paths are repository-relative. api code runs from `api/`, so `domain/…` in imports means `api/domain/…` on disk.

- api: `api/domain/`, `api/application/`, `api/adapters/persistence/`, `api/api/routes/`, `api/api/schemas/`, `api/tests/`
- ui: `ui/app/`, `ui/app/api/`, `ui/components/`, `ui/lib/`, `ui/lib/i18n/`
- Leave the owner's unrelated uncommitted changes (`api/application/notebooks.py`, `api/application/ports.py`, `api/adapters/persistence/notebooks.py`, `api/tests/test_notebooks_application.py`) as they are; add to those files only where a task says so.
