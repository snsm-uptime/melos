# Tasks: Spanish by Default, with English and Spanish for Every Screen

**Input**: Design documents from `specs/063-spanish-default-i18n/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/ui-language.md, quickstart.md

**Organization**: Grouped by user story (spec.md: US1 P1 Spanish unless the member chose otherwise, US2 P1 choose English or Spanish, US3 P1 every screen in the chosen language, US4 P2 first paint in the right language). Phase 2 builds the single language source every story needs (locale rules, cookie helper, server function, provider, hook). **This feature is ui only: no api change, no migration, no new library** (plan). Language is saved with the existing `PATCH /auth/me`; the authentication layer is not touched.

**Tests**: The spec does not request TDD, but constitution §6 requires tests, so test tasks are included.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1, US2, US3, US4 (story phases only)
- Paths are repository-relative. ui code runs from `ui/`.

## Path Conventions

- ui: `ui/app/`, `ui/components/`, `ui/lib/`, `ui/lib/i18n/`
