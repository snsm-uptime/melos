# Tasks: Capture a Recipe from a Photo

**Input**: `specs/041-capture-recipe-photo/` (plan.md, spec.md, research.md, data-model.md, contracts/capture-picture-api.md, contracts/ports.md, contracts/disclaimers-preference.md, quickstart.md, image-processing-prd.md)

**Tests**: Included. Constitution principle 6 requires domain tests, fake-port application tests, Compose integration tests and vitest, and the spec's success criteria (SC-003, SC-004, SC-005, SC-006, SC-008, SC-008a, SC-008b, SC-008c, SC-009) are automated checks. Write each test task before the code it covers and see it fail first. SC-001, SC-002, SC-006 (real assistant), SC-007 need the real assistant or people: they are walked by hand (Phase 6).

**Organization**: by user story from spec.md. US1 (P1) picture → draft → save, with the Handwritten switch, progress, and the disclaimer toast and its account option; US3 (P1) the photo is not kept beyond the compressed preview, and the preview pop-up; US2 (P2) refusals and messages. The image type and size rules, the image pipeline (FR-026), and the extractor's picture mode are foundational: every story calls them, and an unchecked image must never reach the assistant, even for a moment.

- **[Story]**: US1, US2, US3 (spec.md user stories)

Run api commands in this worktree's Compose project only (`./scripts/compose-up.sh -d`); never start a second project with the main `.env` (shared pgdata). New libraries: `Pillow`, `NumPy`, `pillow-heif` (approved for spec 041; constitution 2.1.0 and 2.1.1). No new setting: `GEMINI_IMAGE_TIMEOUT_S` already exists (`api/api/settings.py` `load_gemini_settings().image_timeout_s`, default 30).
